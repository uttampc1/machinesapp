Note: Machine name is obtained from the hostname command on each machine. This field may need periodic update if it changes due to a new OS install or other system changes.
Reserve / Release a Machine
SSH into the machine and run:
machine-reserve <email | name> to reserve  │  machine-release to release  │  machine-status to check status
These commands update the machine's MOTD, broadcast to logged-in users via wall, and update this inventory database.
NOTE: The machine itself is the source of truth for reservation status and availability.
🔧 Setup — If scripts are not installed on your machine
1. Clone the repo:  git clone https://github.com/uttampc1/machine-status-scripts.git
2. Follow the setup instructions in the repo's README.md
Other Terminal Commands
list_machines  │  show_machine -m <name>  │  add_machine --interactive  │  update_machine -m <name>  │  delete_machine -m <name>  │  update_machine_status -m <name> -s reserved [-r user]
⚠ Special Case — Remote Reservation: If the target machine cannot reach the inventory server (network isolation, firewall, etc.), you can update its reservation status from any machine that can reach the server:
update_machine_status -m <machine_name> -s reserved -r <your_name>
Note: This only updates the database. The machine's local MOTD and wall broadcast will not be updated. Run machine-reserve on the machine itself when connectivity is restored.
